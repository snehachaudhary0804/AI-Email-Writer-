✉️ AI Email Writer

An AI-powered MERN stack application that generates professional, personalized, and context-aware emails using Large Language Models (LLMs). The platform helps users create formal, informal, business, and custom emails instantly with AI assistance.

---

🚀 Features

- 🤖 AI-generated email content
- 📝 Smart subject line generation
- 🎯 Tone customization (Formal, Professional, Friendly, Casual)
- 📧 Email reply suggestions
- 🌐 Responsive modern UI
- 🔐 Secure user authentication
- 📂 Save and manage generated emails
- ⚡ Fast API response handling

---
