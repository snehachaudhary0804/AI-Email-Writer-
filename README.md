✉️ AI Email Writer

An AI-powered MERN stack application that generates professional, personalized, and context-aware emails using Large Language Models (LLMs). The platform helps users create formal, informal, business, and custom emails instantly with AI assistance.

---

🚀 Features

- 🤖 AI-generated email content
- 📝 Smart subject line generation
- 🎯 Tone customization (Formal, Professional, Friendly, Casual)
- 📧 Email reply suggestions
- 🌐 Responsive modern UI
- 🔐 Secure user authentication
- 📂 Save and manage generated emails
- ⚡ Fast API response handling

---

⚙️ Installation & Setup

1️⃣ Clone Repository

git clone https://github.com/yourusername/AI-Email-Writer.git

2️⃣ Navigate to Project

cd AI-Email-Writer

3️⃣ Install Dependencies

Frontend

cd client
npm install

Backend

cd server
npm install

---

🔑 Environment Variables

Create a ".env" file inside the server folder and add:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key

---

▶️ Run Application

Start Backend

cd server
npm start

Start Frontend

cd client
npm start
